# Wine Quality Analysis

## Description
This repository contains a statistical analysis of wine quality. The primary goal is to understand the relationships between various physicochemical properties of wine and its perceived quality. The analysis utilizes linear regression techniques performed in Microsoft Excel to identify key characteristics that influence wine taste and quality.

## How to Use/Reproduce Analysis
The analysis is contained within the `wine_analysis.xlsx` Excel file. To reproduce or examine the analysis:
1. Ensure you have Microsoft Excel or a compatible spreadsheet program installed.
2. Open `wine_analysis.xlsx`.
3. Review the data, formulas, and regression analysis performed within the spreadsheet.
4. The `Wine_analysis_v1.pdf` document may contain further explanations or a report of the findings.
